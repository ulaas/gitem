GITEM

Rip through history. Crush merge conflicts. Ship.

A fast, native Git client with a commit graph, a repo-aware editor, and its own diff and merge tools. For Windows, macOS and Linux. Free and open source.

Built for the heavy lifting

01 · History

Every branch. Every merge. Laid bare.

A commit graph with lanes you can fold, badges for branches and tags, search with highlights and a minimap. Columns you drag, resize and hide. Click a commit and its details, files and diff are right there.

02 · Changes

Stage with surgical precision.

Files, diff and commit message on one screen. Stage a whole file, one hunk or a single line. Point at a file and it offers what you'd do next: open it, throw the change away, or stage it. Split work into several commits with the Composer.

03 · IDE mode

Edit right where you commit.

Flip on IDE mode and the Files tree opens files for editing: syntax colours, several carets, find and replace, folding and an outline. It knows the repository. Marks beside each line show what changed, and one change at a time can be staged or reverted from the gutter.

04 · Diff

Diffs that don't flinch.

Side by side or unified, with the words that changed picked out, syntax colours and image comparison. Stage or discard right from the diff. It also works as git's own difftool.

05 · Merge

Merge conflicts? Handled.

Ours, the result and theirs, side by side, scrolling together. Take a side, take both, or edit the result by hand, one conflict at a time. Your own edits are never thrown away. It also works as git's own mergetool.

Fully loaded

  • Rebase without fear

    Drag commits into order, squash, reword, drop, and check for conflicts before anything runs.

  • Undo that means it

    Took the wrong turn? Undo a merge, rebase, reset, discard or branch delete from the toolbar.

  • Pull requests, in place

    GitHub, GitLab, Bitbucket, Azure DevOps and Gitea: review, comment, approve and merge, self-hosted too.

  • AI, on your terms

    Commit messages, explanations, review and conflict help, through the provider you choose, and only when you ask.

  • Dock it your way

    Drag tabs into splits, zoom a pane to fill the window, and keep your own layouts.

  • Find anything

    One palette for commands, branches, files and commits. Search history by message, author, file or change.

  • Bisect, reflog, more

    Hunt a regression, recover lost work, tame submodules, hooks, LFS and sparse checkouts.

  • Twelve themes

    Dark and light themes, any accent colour, colour-blind safe diffs and reduced motion.

  • Native and fast

    Written in Rust and drawn on the GPU. It stays responsive on very large histories, diffs and files.

Trust nothing. Ask first.

A repository can arrive with config that runs programs. gitem treats every one as untrusted until you say otherwise.

  • Nothing runs behind your back. Config that would start a program, such as filters, drivers or core.fsmonitor, stays off until you agree. Reads never run hooks.
  • Destruction asks first. Force pushes, resets and discards show the exact git command before they happen.
  • Secrets stay secret. Tokens live in your system's credential store and are masked wherever a URL is shown.
  • Nothing reports on you. No telemetry. AI requests only go where you point them, and only when you ask. A daily look for a newer release asks GitHub and sends nothing about you; you can turn it off, and an update is downloaded only when you click.

Lock and load

gitem builds from source with the Rust toolchain and runs on the git you already have (2.38 or newer).

git clone https://github.com/ulaas/gitem
cd gitem
cargo build --release
./target/release/gitem path/to/your/repo
